# Arcane Spire: First Year

An original 3D wizard-school action adventure. Explore **Crescentwick Academy**, sort into one of four houses, learn original spells, duel in real time, fly brooms in **Aetherchase**, and hunt secret passages.

**Not affiliated with any existing wizard franchise.** All names, houses, spells, and designs are original.

## Stack
Three.js + Vite + Node WebSocket server.

## Local
```bash
npm ci
npm run build:local
npm start
# open http://localhost:8080
```

## Deploy
`scripts/deploy.sh` pushes `main` and triggers a Render deploy.
